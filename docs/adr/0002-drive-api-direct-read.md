# ADR-0002: スマホ → クラウド: Drive API 直読み（GCS非経由）

## 状態
確定

## 決定
エクスポートを Drive の子供別フォルダへ共有保存し、Cloud Run job が Drive API でそのフォルダを直接読む。GCS は使わない。

## 根拠
スマホ側操作を標準機能の「共有 → Drive」だけで完結させ、Drive→GCS 同期という余計な一段を消すことで日常運用の摩擦を最小化する。Drive は既に利用中で馴染みがある。代償の Drive API 実装はサーバー側の一度きりの作業。

## 却下した代替案
- GCS へ直接アップロードするアプリ経由 → 新規アプリの信頼性・認証の手間
- 署名付き URL + スマホショートカット → ショートカット構築と URL 有効期限管理の手間
- メール経由 → 結局 functions/API が必要で「外部処理を増やさない」方針と相性が悪い
- Termux + gsutil → Termux 環境を使っていないため不採用

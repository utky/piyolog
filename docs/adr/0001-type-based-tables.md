# ADR-0001: 種別ごとのテーブル（タイプ別テーブル方式）

## 状態
確定

## 決定
イベント種別ごとに専用テーブル/スキーマを持つ（共通縦持ち1テーブルではなく）。

## 根拠
「特定のイベントだけで集計する」用途が主であり、種別ごとテーブルならビューを介さず直接 SQL で集計できる。

## 補足
構造化する列を持たない種別(自由記述型等)は1モデルに集約する形で運用する → [ADR-0011](0011-intermediate-event-type-models.md)。

## トレードオフ
新種別が増えるとテーブル追加・パイプライン拡張が必要。ただし種別は大きく変化しない想定（方針P）であり、許容できる。

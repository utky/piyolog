# 既知イベント種別リスト

フェーズ2(種別棚卸し)の成果物。`sql/analysis/extract_event_types.sql` を BQ の
`piyolog_raw.export_files` 全件(全期間・子供2名、2021-12〜2026-06、計67ファイル)に対して
実行し、種別の和集合を確定したもの。

`overview.md` §5.3 の種別グループはこのリストに基づく。

## 抽出方法の注記

当初の設計ドキュメントでは「イベント開始行は `HH:MM` の直後がタブ区切り」としていたが、
実データを確認したところ**タブ文字は存在せず、実際は半角スペース区切り(基本3スペース、
まれに1スペースの例外あり)**だった。本リストの抽出および `overview.md` /
`piyolog_raw_layer_spec.md` / dbt SKILL.md の記述はこの実データ調査結果に合わせて修正済み。

## 長尾: 種別欄への自由記述(単発)

上記とは別に、種別欄に体調や出来事をそのまま自由記述したケースが**17種類・計18件**
(全期間中、各1〜2件のみ)確認された。頻度が既知種別と比べて桁違いに少なく、内容に
個人の健康状態や具体的な出来事(通院・体調急変時の記録など)を含むものがあるため、
**本ドキュメントには内容を転記しない**。内訳の傾向のみ記す。

| カテゴリ | 件数(distinct) | 備考 |
|---|---:|---|
| 体温の直接入力(数値のみ/数値+症状メモ) | 5 | `体温` 種別を使わず種別欄に温度を直書きしたもの |
| 保育の出席区分 | 2 | 半日/全日の記録 |
| 追加の身体計測 | 1 | 頭囲以外の計測項目 |
| 自由記述の出来事メモ | 9 | 体調急変・受診・救急要請等の詳細記録を含む |

これらは方針P(既知種別を固定定義し、未知種別は警告で検知)における「未知種別」の
典型例として扱う。staging 実装時、既知33種別のリストに一致しないイベント行は
警告ログを出しつつ `その他` 相当として扱う(具体的な検知・格納方針はフェーズ3で設計)。

## 再現方法

```bash
bq query --project_id=lofilab --use_legacy_sql=false < sql/analysis/extract_event_types.sql
```

新しい月次データが取り込まれた後に再実行し、このリストとの差分(未知種別の有無)を
確認する運用を想定する。
